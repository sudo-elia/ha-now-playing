For install:

1) Inside background.js edit the HA_URL with your ip/link of home assistant.
2) paste all the python script inside a new folder "python_scripts" of configuration.yaml position,
3) copy and paste the content of configuration.yaml below you configuration.yaml.
4) Create new folder "sc-ha-series" and new json file "watchlist.json", inside www/
5) Add the new automation
6) Reboot home assistant and enjoy lol
